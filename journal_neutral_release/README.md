# Journal-neutral release package for SQRCD_EQF

Generated: 2026-08-20

This folder provides a journal-independent release package for the manuscript and computational study "An Evidence Qualification Framework for Annotation-Level Formula Discrimination in Traditional Chinese Medicine." It is not a record of acceptance, publication, or active consideration by any journal.

## Contents

1. `Supplementary_Information.pdf` — readable supplementary information containing supplementary tables, supplementary figures, assessor procedure record, and stopped/not estimable decision rules.
2. `Core_machine_readable_outputs.zip` — derived formula identity, annotation, subformula, Formula Discrimination Index, Shapley, perturbation, null-model, and cross-formula benchmark outputs.
3. `Deidentified_paired_assessor_ratings.csv` — 750-row paired evidence-state rating matrix with formula ID, rubric item, domain, de-identified assessor ratings, agreement flag, and disagreement type.
4. `Data_and_code_manifest.csv` — index of archived files, repository locations, reuse status, and licence notes.
5. `Data_Availability_Statement.txt` — journal-neutral data and code availability language.
6. `REPRODUCIBILITY.md` — software, expected checks, and versioned-record notes.

This release contains repository-authored code, derived outputs and de-identified reproducibility data. It excludes raw third-party database exports, raw assessor workbooks, assessor initials/dates/signatures, editorial correspondence, credentials, and local absolute-path-only working files.
