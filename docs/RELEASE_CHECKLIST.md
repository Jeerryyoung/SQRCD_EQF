# Submission release checklist

- [ ] Repository links resolve and are reciprocal across GitHub, OSF and Zenodo.
- [ ] README, `CITATION.cff`, manuscript and Zenodo metadata use the same title, authors and license.
- [ ] No manuscript draft, cover letter or blinded-review material is present.
- [ ] No raw rater workbook, initials, rating dates or free-text notes are present.
- [ ] No credentials, email addresses or local absolute paths are present.
- [ ] Third-party database redistribution rights have been checked.
- [ ] Tests pass in a clean environment.
- [ ] `provenance/CHECKSUMS.sha256` has been rebuilt.
- [ ] Git tag and commit SHA are frozen.
- [ ] Zenodo version DOI corresponds to the exact tagged snapshot.
- [ ] Manuscript Data and code availability cites the tag and version DOI.
