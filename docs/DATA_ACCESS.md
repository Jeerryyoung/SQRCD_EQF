# Data access and disclosure matrix

| Material | GitHub | Zenodo | OSF | Rationale |
|---|---|---|---|---|
| Analysis code, configuration and tests | Public | Archived snapshot | Link only | Required for computational reproducibility |
| Derived summary tables and figure source data | Public | Archived snapshot | Link only | Supports reported numerical results |
| Registration protocol and amendments | Link only | Link/metadata | Registration record | Preserves time-stamped analytic intent |
| Final accepted manuscript | After journal policy permits | Optional accepted-manuscript version | Optional link | Avoids blind-review and publisher-policy conflicts |
| Submission draft and cover letter | No | No | No | Editorial and blind-review material |
| Raw rater workbooks, initials and dates | No | No | Restricted source record only | Protects assessor identity and blinding record |
| De-identified agreement summaries | Public | Archived snapshot | Link only | Reproduces inter-rater results without identity data |
| Third-party database exports | Only if redistribution is permitted | Only if permitted | Source links | Original database terms remain controlling |
| GEO expression data | Accession and retrieval code | Normally no duplicate | Accession | Avoids unnecessary re-hosting |
| Credentials, tokens and local paths | Never | Never | Never | Security and privacy |

Public release is not a substitute for reporting database versions, access dates, identifiers, entity-resolution rules and exclusion decisions.
