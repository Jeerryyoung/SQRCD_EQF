All data underlying the findings are available within the manuscript, its Supporting Information files, and the versioned Zenodo repository at https://doi.org/10.5281/zenodo.21873862. The Supporting Information includes the de-identified paired assessor-rating matrix and machine-readable summary outputs. Complete subformula, perturbation, benchmark, provenance and figure-source data are included in the Zenodo release. Analysis code and configuration files are available from the project GitHub repository at https://github.com/Jeerryyoung/SQRCD_EQF. Third-party database records are redistributed only where permitted by their respective licences; source identifiers, retrieval dates and processing scripts are provided to enable reconstruction.
